webhook Configuración del Webhook

1. Desplegá este script como Aplicación Web:

Implementar → Nueva implementación → Aplicación web → Acceso: Cualquier usuario

2. Copiá la URL de la Web App y pegala en Meta como URL de devolución de llamada

3. En Identificador de verificación poné el valor que configuraste en Script Properties como VERIFY_TOKEN

4. Hacé clic en "Verificar y guardar"

key Script Properties necesarias

Configurá estas propiedades en ⚙️ Configuración del proyecto → Propiedades del script:

  • WHATSAPP_TOKEN — Token de acceso de Meta (generalo en Meta for Developers)
  • VERIFY_TOKEN — Un token seguro inventado por vos (ej: kaizen_whatsapp_2026)
  • WABA_ID — ID de tu cuenta de WhatsApp Business (lo encontrás en Meta Business Suite → Configuración de WhatsApp)
  • SPREADSHEET_ID — (opcional) Se crea automáticamente si no existe
